# Полигон — страницы турниров

Статический сайт, который сам собирается из листа «Турниры» Google-таблицы:

- `/t/<ID>/` — страница каждого турнира: описание, даты, уровни, взнос, кнопка регистрации, файл для календаря, разметка `SportsEvent` для Яндекса и Google;
- `/goroda/<город>/`, `/uroven/<уровень>/`, `/vid/<вид спорта>/`, `/za-rubezhom/`, `/arhiv/` — посадочные страницы;
- `sitemap.xml`, `robots.txt`, `404.html`.

Сайт пересобирается каждые 3 часа. Новый турнир, добавленный в таблицу, появится на своей странице автоматически.

## Как запустить (один раз, ~15 минут)

1. **Репозиторий.** На github.com создайте новый публичный репозиторий, например `polygon-pages`. Загрузите в него все файлы из архива (кнопка *Add file → Upload files*), включая папку `.github`.
2. **GitHub Pages.** *Settings → Pages → Build and deployment → Source:* выберите **GitHub Actions**.
3. **Первая сборка.** *Actions → «Сборка страниц турниров» → Run workflow*. Через 1–2 минуты сайт будет доступен по адресу вида `https://<логин>.github.io/polygon-pages/`.
4. **Свой адрес.** У регистратора домена thepolygon.ru добавьте DNS-запись:
   `turniry  CNAME  <логин>.github.io.`
   Затем в *Settings → Pages → Custom domain* впишите `turniry.thepolygon.ru` и включите *Enforce HTTPS* (сертификат выпускается до суток).
   После этого в *Settings → Secrets and variables → Actions → Variables* создайте переменную `POLYGON_PAGES_URL` со значением `https://turniry.thepolygon.ru` и перезапустите сборку — ссылки и sitemap переключатся на новый адрес. Пока переменной нет, сайт собирается под `https://unklev.github.io/polygon-pages`.
5. **Поисковики.** Добавьте `turniry.thepolygon.ru` в Яндекс Вебмастер и Google Search Console и отправьте `https://turniry.thepolygon.ru/sitemap.xml`.

## Полезно знать

- Данные берутся из опубликованной CSV-копии листа «Турниры». Если она не ответила — из запасного адреса через Apps Script.
- Турниры с «Показывать = нет» на сайт не попадают.
- GitHub приостанавливает расписание, если в репозитории 60 дней не было изменений. Тогда во вкладке *Actions* появится кнопка включить его снова (или просто сделайте любой коммит).
- Проверить локально: `python build.py sample_data.csv` — сайт соберётся в папку `public/`.
